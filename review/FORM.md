# Quick paper review

These are invented committee papers. We want to check whether our expected answers are fair, not ask you to approve a real service.

Read the shared paper once. At each passage marker, use the passage from Version X, then consider the same paper with Version Y instead. Nothing else changes. Allow about five minutes per pair. Do not open answer_key.json or RESULTS.md before answering.

For each pair, answer:

(a) Version X: does the evidence back the headline claim for the decision being made? **yes / no / unsure**

(b) Version Y: does the evidence back the headline claim for the decision being made? **yes / no / unsure**

(c) Optional one line: anything clinically implausible or unfair?

For the COVID papers, the headline means the exact claim in the final section. Supporting that claim does not require agreeing with the policy.

Start with **F3b, G4, F2, covid-surveillance**. Next try **F4, G3**, where reasonable readers may differ. Then F1, F5, G1, G2 and covid-masking. Just the first four to six pairs is still useful.

Use responses/TEMPLATE.csv: save a copy as joint.csv. Answer each pair together and record one agreed answer. If you disagree, write "unsure" and note both views in the comment. Leave unread pairs blank. Handwritten answers on printed papers are fine; copy them into the CSV afterwards.
